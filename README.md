# Jeusef Mendoza Portfolio

A single-page portfolio for CC107 Activity 4, using semantic HTML, responsive CSS, and JavaScript.

## Files
- index.html: introduction, biography, projects, skills, and contact.
- style.css: layout, responsive breakpoints, and light/dark themes.
- script.js: mobile menu, persistent theme toggle, project dialogs.
- assets/: portrait and monogram favicon.

## GitHub Pages submission
1. Sign in to github.com/pupet22 and create a PUBLIC repository named portfolio.
2. Upload the contents of this ZIP to the repository root (index.html must be at the root).
3. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch.
4. Choose main and / (root), then Save.
5. Wait for GitHub Pages to show its live URL and verify the photo, theme toggle, menu, and project buttons.
6. Submit both the public repository link and the live GitHub Pages URL in MS Teams.

Expected links after you create and publish the repository:
Repository: https://github.com/pupet22/portfolio
GitHub Pages: https://pupet22.github.io/portfolio/
These are expected URLs, not already-created resources.

A separate Sites deployment is available, but the activity specifically names GitHub Pages for its deployment bonus.

## Personalization
Project visuals are illustrative UI studies rather than actual screenshots. Replace them with screenshots and add source/demo links as your projects become publicly available.

## Vercel
This is a buildless static site. Import the source repository into Vercel, select Other as the framework, leave the build command empty, and serve the repository root. The HTML, CSS, JavaScript, and assets should be at the repository root as packaged here.
