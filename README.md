# Jeusef Sonn P. Mendoza Portfolio

A single-page portfolio for CC107 Activity 4, using semantic HTML, responsive CSS, and JavaScript.

## Files
- index.html: introduction, biography, projects, skills, and contact.
- style.css: layout, responsive breakpoints, and light/dark themes.
- script.js: mobile menu, persistent theme toggle, project dialogs.
- assets/: portrait and monogram favicon.
